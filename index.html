Image workflow

Before compressing a photo, decide where it will be used.

“Smaller” is not a complete requirement. A file can be lightweight but still have more pixels than its destination needs, or look damaged because quality was reduced too far. Start with the intended display size, then compare the exported file at that size.

  • Record the target width and height.
  • Compare format and file size after export.
  • Open the actual exported file at its intended display size.

Text workflow

Define what a duplicate is before removing one.

Two lines may look equal yet represent different values because of spacing, capitalization, order, or an attached label. A safe cleanup starts with the equivalence rule, preserves the original input for comparison, and makes the change visible before anyone copies the result onward.

  • Choose an exact or normalized matching rule.
  • Keep source order unless you explicitly want sorting.
  • Compare the before and after lists before reuse.

QR workflow

A QR image is not finished until the final file scans.

A preview can look sharp while a printed, downsized, or recompressed QR image fails on a real phone. Scan the exported file itself, then scan the printed version at the expected viewing distance. Check the destination URL as well as whether the camera recognizes the code.

  • Scan the exported asset from another device.
  • Check the resolved destination, including its path.
  • Repeat after printing or placing it in the final layout.

Audio workflow

Use the waveform to choose the cut. Use playback to approve it.

A waveform helps locate silence, speech, and transitions, but it cannot tell you whether the resulting sentence still has the intended meaning or whether a cut feels abrupt. Listen from a few seconds before the cut to a few seconds after it, using the final format.

  • Mark the intended in and out points.
  • Listen across each edit boundary.
  • Check the exported file with the playback device your audience will use.
