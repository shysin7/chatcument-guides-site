날짜 차이 계산 실습: 시작일을 포함하면 무엇이 달라질까

일정에서 날짜 차이와 포함 일수의 차이를 구분하는 기초 가이드.

실제 서비스 인터페이스 화면이며 입력 텍스트는 합성 예제입니다.

무엇을 세는지 먼저 말합니다

두 날짜 사이의 차이를 묻는지, 시작일과 종료일을 모두 포함한 날짜 수를 묻는지에 따라 답이 달라집니다. 행사 기간, 숙박 수, 마감일까지 남은 시간은 같은 표현처럼 보여도 서로 다른 규칙을 쓸 수 있습니다.

시간대와 입력 형식을 통일합니다

날짜만 있는 값과 시각이 포함된 값, 서로 다른 시간대의 값은 단순히 빼면 예상과 달라질 수 있습니다. 계산 전에는 날짜 형식과 기준 시간대를 한 문장으로 정합니다.

사람이 읽는 일정표와 대조합니다

계산 결과를 일정표의 시작과 끝에 대입해 보세요. 포함 규칙을 한 줄로 적어 두면 다음 사람이 같은 숫자를 다른 의미로 해석하는 일을 줄일 수 있습니다.

최종 확인

결과 파일을 편집기 미리보기만으로 승인하지 말고, 실제로 쓰일 크기와 위치에서 다시 확인합니다. 도구 화면과 옵션은 바뀔 수 있으므로 현재 사용 방법은 연결된 공개 도구 페이지에서 확인하세요.
