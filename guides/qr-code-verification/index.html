QR 코드 수업: 그림을 만든 다음에 해야 할 검증

QR 코드를 만든 뒤 최종 파일, 목적지, 실제 스캔을 확인하는 실습 가이드.

생성본이 아니라 최종 자산을 스캔합니다

화면에서 바로 읽힌 QR 코드가 인쇄본, 축소본, 메신저로 다시 저장된 이미지에서도 읽힌다는 뜻은 아닙니다. 실제 배포할 파일을 다른 기기의 카메라로 스캔하는 순서를 정합니다.

열렸다는 사실만으로 끝내지 않습니다

스캔 뒤에는 주소의 도메인뿐 아니라 경로와 필요한 쿼리 문자열까지 확인합니다. 의도한 랜딩 페이지가 아닌 홈 화면이나 오래된 캠페인 주소로 연결되면 다시 만들어야 합니다.

배치 뒤에 한 번 더 확인합니다

여백을 자르거나 디자인 안에 넣고, 작은 크기로 출력한 뒤에도 다시 스캔합니다. 이 마지막 확인이 생성 화면의 미리보기와 실제 배포물 사이의 차이를 줄입니다.

최종 확인

결과 파일을 편집기 미리보기만으로 승인하지 말고, 실제로 쓰일 크기와 위치에서 다시 확인합니다. 도구 화면과 옵션은 바뀔 수 있으므로 현재 사용 방법은 연결된 공개 도구 페이지에서 확인하세요.
