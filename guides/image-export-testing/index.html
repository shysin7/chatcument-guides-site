The preview is not the deliverable: testing image exports

A practical acceptance test for checking an exported image after an in-browser edit.

This is a service-interface screenshot with synthetic example input. It is not a benchmark or export result.

Inspect the actual exported file

A visible preview tells you that an interface rendered something; it does not prove that the intended file is ready. Open the saved result and confirm its name, extension, dimensions and visible content.

Use the target context

Place the exported image into the space where it will appear. A square thumbnail, a wide hero and a narrow mobile card reveal different issues even when they use the same source image.

Record what was approved

Keep a small note with the input, chosen settings and date of review. It gives the next reviewer a concrete basis for comparing a revision without pretending that one example guarantees every image.

Final check

Open the exported result or use it at the intended size before approving it. Interfaces and options can change, so confirm the current workflow on the linked public tool page.
