썸네일이 잘리는 이유: 크기 조절과 잘라내기를 구분하세요

썸네일 제작에서 리사이즈와 크롭을 구분하고 원본 비율을 지키는 실전 가이드.

실제 서비스 인터페이스 화면이며 입력 텍스트는 합성 예제입니다.

크기 조절은 장면을 버리지 않습니다

크기 조절은 가로와 세로의 픽셀 수를 바꾸되 원래 장면의 비율을 유지합니다. 사진이 가로 4:3이라면 줄인 뒤에도 4:3으로 남습니다. 먼저 목적지의 표시 폭과 높이를 적고, 그 안에서 비율을 유지할 수 있는지 확인하세요.

크롭은 보여 줄 범위를 고르는 일입니다

정사각형 썸네일에 가로 사진을 넣을 때는 일부가 잘립니다. 이때는 제품, 얼굴, 제목처럼 반드시 남아야 하는 요소가 프레임 안에 들어오는지 먼저 판단해야 합니다. 자동 중앙 크롭만 믿기보다 중요한 피사체를 기준으로 자르는 위치를 검토하세요.

전달 전에 두 크기를 다시 엽니다

목록용 작은 썸네일과 상세 페이지용 큰 이미지를 같은 파일로 해결하려 하지 마세요. 각각을 실제 표시 크기에서 열고, 글자·모서리·주요 피사체가 읽히는지 확인합니다. 원본과 결과의 파일명을 구분해 보관하면 다음 수정도 추적할 수 있습니다.

최종 확인

결과 파일을 편집기 미리보기만으로 승인하지 말고, 실제로 쓰일 크기와 위치에서 다시 확인합니다. 도구 화면과 옵션은 바뀔 수 있으므로 현재 사용 방법은 연결된 공개 도구 페이지에서 확인하세요.
