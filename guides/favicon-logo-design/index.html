작은 파비콘을 만들 때 긴 로고를 그대로 줄이면 안 되는 이유

브라우저 탭처럼 작은 공간에서 로고를 알아보기 쉽게 만드는 파비콘 점검 가이드.

실제 서비스 인터페이스 화면이며 입력 텍스트는 합성 예제입니다.

작은 크기에는 다른 판단이 필요합니다

긴 워드마크를 아주 작은 정사각형으로 줄이면 글자가 뭉개집니다. 파비콘은 전체 로고의 축소본보다, 작은 공간에서 남길 한두 개의 형태를 선택하는 작업에 가깝습니다.

원본을 버리지 않고 변형합니다

파비콘용 심볼이나 첫 글자를 만들더라도 정본 로고는 별도로 보관합니다. 출력 크기를 구분해 저장하고 투명도와 여백이 변하지 않는지 확인합니다.

브라우저 탭에서 확인합니다

확대된 편집 화면은 실제 탭보다 훨씬 큽니다. 내보낸 파일을 탭과 북마크처럼 작은 위치에서 열어 주변 아이콘 사이에서도 구분되는지 봅니다.

최종 확인

결과 파일을 편집기 미리보기만으로 승인하지 말고, 실제로 쓰일 크기와 위치에서 다시 확인합니다. 도구 화면과 옵션은 바뀔 수 있으므로 현재 사용 방법은 연결된 공개 도구 페이지에서 확인하세요.
