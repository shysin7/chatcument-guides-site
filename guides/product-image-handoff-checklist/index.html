상품 이미지 전달이 반복해서 돌아올 때, 파일보다 먼저 정할 기준

상품 이미지 전달 전 크기·용도·수정 범위를 합의해 재작업을 줄이는 체크리스트입니다.

실제 서비스 인터페이스 화면이며 입력 텍스트는 합성 예제입니다.

어디에 놓일 이미지인지 먼저 적으세요

상품 상세, 목록 썸네일, 광고 소재는 같은 사진이라도 필요한 비율과 여백이 다릅니다. 받는 사람에게 파일만 보내기보다 사용 위치와 필요한 가로세로 비율, 최소 표시 크기를 함께 전달하세요.

수정 가능한 것과 지켜야 할 것을 나누세요

용량 축소, 크롭, 배경 정리, 워터마크 추가는 서로 다른 변경입니다. 색상·로고·제품 비율처럼 바꾸면 안 되는 요소와 허용되는 변경을 구분해 적으면 다음 검수가 빨라집니다.

예시 파일로 합의 상태를 저장하세요

최종본 이름, 원본 보관 위치, 전달용 버전을 구분하고 승인된 한 장을 기준 예시로 남기세요. 새 파일이 오면 예시와 같은 화면 크기에서 열어 보고 용량과 선명도를 함께 확인합니다.

최종 확인

결과 파일을 편집기 미리보기만으로 승인하지 말고, 실제로 쓰일 크기와 위치에서 다시 확인합니다. 도구 화면과 옵션은 바뀔 수 있으므로 현재 사용 방법은 연결된 공개 도구 페이지에서 확인하세요.
